# 🎮 Rock, Paper, Scissors Game

A simple, interactive, and responsive web-based **Rock, Paper, Scissors** game built from scratch using vanilla web technologies. Play against an automated computer opponent and test your luck!

[👉 Live Demo Link Here](https://rishu-nirmal.github.io/Game/)

---

## 🚀 Features

* **Real-time AI Opponent:** Play against a computer that generates randomized counter-moves.
* **Live Score Tracking:** Tracks your wins, losses, and ties throughout the session.

---

## 🛠️ Technologies Used

* **HTML5:** Structures the game canvas, scoring board, and action triggers.
* **CSS3:** Delivers custom typography, layouts using Flexbox/Grid, and hover animations.
* **JavaScript (ES6):** Controls DOM manipulation, application state, and core game logic.
